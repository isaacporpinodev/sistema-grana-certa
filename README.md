# GranaCerta

Controle financeiro pessoal de forma simples e organizada.

## Objetivo
Desenvolver um sistema web para registrar entradas e saídas, acompanhar saldo e organizar movimentações por mês.

## Tecnologias
- HTML
- CSS
- JavaScript

## Funcionalidades da primeira versão
- Cadastro de movimentações
- Edição de movimentações
- Exclusão de movimentações
- Filtro por mês
- Tema claro e escuro
- Persistência com localStorage

## Estrutura do projeto
- `index.html`
- `css/`
- `js/`
- `assets/`

## Planejamento futuro
- Login de usuário
- Dados separados por usuário
- Deploy do projeto
